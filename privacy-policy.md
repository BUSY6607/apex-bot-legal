# Privacy Policy

**Effective Date:** May 2, 2026
**Bot Name:** Apex
**Contact:** Available via the support server

---

## 1. Introduction

This Privacy Policy explains what data Apex ("the Bot") collects, how it is used, and how it is stored. By adding Apex to your Discord server or interacting with it, you agree to the practices described in this policy.

---

## 2. Data We Collect

Apex collects and stores the following data solely to provide its features:

### Stored in Database (MongoDB)
| Data | Purpose |
|---|---|
| Guild ID | Identifying your server's configuration |
| User IDs | Moderator actions, report submissions, ticket ownership |
| Channel IDs | Log channels, ticket channels, report channels |
| Role IDs | Support roles, configured moderation roles |
| Message IDs | Ticket panel tracking |
| Report content | Text and attachments submitted through the report system |
| Ticket transcripts | Closed ticket history |

### Temporarily in Memory (Not Stored)
| Data | Purpose |
|---|---|
| Message content | Report system buffer — held until user types "done", then cleared |
| File attachments | Forwarded to staff review, not permanently stored |

---

## 3. Data We Do NOT Collect

- Passwords or authentication tokens
- Email addresses
- Payment information
- IP addresses
- Personal information outside of Discord

---

## 4. How We Use Your Data

Data collected by Apex is used exclusively to operate the bot's features:

- **Moderation logs** — storing guild/channel/user IDs to route log embeds to the correct channels
- **Ticket system** — creating, tracking, and closing support tickets
- **Report system** — receiving and forwarding user reports to server staff
- **Interaction Studio** — storing panel configurations per server

We do not sell, share, or use your data for advertising or analytics.

---

## 5. Data Retention

- Server configuration data is retained as long as Apex remains in your server
- When Apex is removed from a server, its configuration data may remain in the database but is no longer actively used
- You may request deletion of your server's data by contacting us through the support server

---

## 6. Third-Party Services

Apex uses the following third-party services:

- **Discord API** — for all bot functionality (subject to [Discord's Privacy Policy](https://discord.com/privacy))
- **MongoDB Atlas** — for database storage (subject to [MongoDB's Privacy Policy](https://www.mongodb.com/legal/privacy-policy))

---

## 7. Children's Privacy

Apex is not directed at children under the age of 13. We do not knowingly collect data from anyone under 13. Discord's own Terms of Service require users to be at least 13 years old.

---

## 8. Changes to This Policy

We may update this Privacy Policy from time to time. Continued use of Apex after changes constitutes acceptance of the updated policy.

---

## 9. Contact

If you have questions or requests regarding your data, please reach out through the official Apex support server.
